# Apuntes GITT 4º

Web de apuntes de las asignaturas de 4º GITT (Universidad de Alcalá). En construcción.

Apuntes interactivos de cuarto del Grado en Ingeniería de Tecnologías de Telecomunicación (mención en Sistemas de Telecomunicación), curso 2026/27. Cada asignatura tiene su propia web dentro de esta: ya están Conmutación y Comunicaciones Ópticas, y Radiación y Radiocomunicación, Circuitos de Comunicación y SEDA están en preparación. Son apuntes de estudiantes, basados en sus notas de clase: no están revisados ni avalados por el profesorado y pueden contener errores.
