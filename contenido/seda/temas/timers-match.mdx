**Idea clave.** Un Timer es un **contador que avanza solo** a un ritmo conocido. Cuando llega a un valor que tú eliges (un **Match**), puede interrumpir, reiniciarse o cambiar un pin. Casi todo se reduce a una cuenta: cuántos «tics» caben en el tiempo que quieres.

## Cómo está hecho un Timer

El LPC1768 tiene **cuatro Timers** (0–3), iguales. Cada uno tiene:

- **PR** (*Prescaler*) y **PC**: dividen el reloj. El contador avanza a $F_{tick} = \dfrac{F_{PCLK}}{PR + 1}$. Con PR = 0 (el de reset), $F_{tick} = F_{PCLK} = 25$ MHz.
- **TC** (*Timer Counter*): el contador de **32 bits**.
- **MR0–MR3**: cuatro registros de **Match**. Un comparador mira en cada tic si TC = MRx.
- **CR0–CR1**: dos registros de **captura** (tema 4).
- Pines: salidas **MATn.0–MATn.3** y entradas **CAPn.0–CAPn.1**.

## a) Interrupción periódica

<Practica n={3} nombre="Servomotor con un Timer" />

Con **MR0I y MR0R** activos, el TC sube de 0 a MR0, interrumpe y vuelve a 0. Cuenta $MR0 + 1$ tics, así que:

$$
T_{int} = \frac{MR0 + 1}{F_{tick}} \quad\Longrightarrow\quad MR0 = F_{tick}\cdot T_{int} - 1
$$

```c
LPC_TIM0->PR  = 0;                     // F_tick = F_PCLK = 25 MHz
LPC_TIM0->MR0 = 25000000 / 1000 - 1;   // 1 ms
LPC_TIM0->MCR = (1 << 0) | (1 << 1);   // MR0I y MR0R
NVIC_EnableIRQ(TIMER0_IRQn);
LPC_TIM0->TCR = 1;                     // arranca

void TIMER0_IRQHandler(void) {
  LPC_TIM0->IR = (1 << 0);             // borrar el flag de MR0
  // … lo que toque cada 1 ms
}
```

Es lo mismo que el SysTick, pero con cualquier Timer y con 32 bits. Si $F_{tick}\cdot T$ no cabe en 32 bits (periodos de minutos), se sube PR.

### Sin reset: el TC corre libre

Si no se reinicia el TC, en cada interrupción se **adelanta el Match**:

```c
void TIMER0_IRQHandler(void) {
  LPC_TIM0->IR = (1 << 0);
  LPC_TIM0->MR0 += N;                  // N = F_tick · T
}
```

Aquí $N = F_{tick}\cdot T$, sin el −1: ya no se cuenta desde 0, sino desde el Match anterior. La ventaja es que **cada Match lleva su propio periodo**, porque ninguno reinicia el contador. Cuando el TC llega a $2^{32}-1$ da la vuelta a 0, y la suma también, así que sigue funcionando.

## b) Señal cuadrada por hardware (sin interrupción)

**EMR** conecta cada Match con su pin MATn.x. Sin entrar en ninguna ISR, el pin puede ponerse a 0, a 1 o conmutar:

Con **toggle** y reset en MR0, el pin cambia cada $MR0 + 1$ tics: dos cambios por periodo.

$$
\frac{T_{out}}{2} = \frac{MR0 + 1}{F_{tick}} \quad\Longrightarrow\quad MR0 = \frac{F_{tick}}{2\cdot F_{out}} - 1
$$

El problema: el reset en MR0 **reinicia el TC para todos los Match**. Con este método sale **una sola frecuencia por timer**.

## c) Varias señales con un timer

Para tener varias frecuencias se juntan los dos trucos: **toggle sin reset** y sumar $N$ en la ISR. Cada Match conmuta su pin y se adelanta medio periodo:

```c
void TIMER0_IRQHandler(void) {
  if (LPC_TIM0->IR & (1 << 0)) {       // ¿ha sido MR0?
    LPC_TIM0->IR = (1 << 0);
    LPC_TIM0->MR0 += N0;               // N0 = F_tick / (2 · F_0)
  }
  if (LPC_TIM0->IR & (1 << 1)) {       // ¿ha sido MR1?
    LPC_TIM0->IR = (1 << 1);
    LPC_TIM0->MR1 += N1;
  }
}
```

Salen **hasta 4 señales** por timer. Hay que mirar en IR **qué Match ha interrumpido**, porque todos comparten la misma ISR. Las señales rápidas interrumpen más veces, y si todas las frecuencias son múltiplos, pueden coincidir y entrar en todos los `if` de una vez.

**Límite de frecuencia.** Entre dos conmutaciones tiene que dar tiempo a entrar en la ISR y ejecutarla. Si en el peor caso coinciden dos señales:

$$
2\cdot(t_{latencia} + t_{ejecución}) \le \frac{T_{out}}{2}
$$

De ahí sale $F_{max}$. Además, cuanto más alta la frecuencia, más tiempo de CPU se come la ISR.

<summary>¿Por qué en la interrupción periódica es MR0 = F_tick·T − 1, pero al sumar en la ISR es N = F_tick·T?</summary>

Con reset, el TC pasa por 0, 1, …, MR0: son $MR0 + 1$ cuentas por periodo, de ahí el −1. Sin reset, el siguiente Match está **N cuentas después** del anterior, así que el periodo es exactamente $N$ tics. *(Respuesta redactada a partir de los apuntes.)*
