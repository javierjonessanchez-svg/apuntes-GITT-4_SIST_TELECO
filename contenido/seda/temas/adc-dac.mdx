**Idea clave.** El **ADC** convierte una tensión del pin en un número de 12 bits (0–4095) y el **DAC** hace lo contrario con 10 bits (0–1023). Los dos van referidos a $V_{REF}$, que en la Mini-DK2 es 3,3 V. Con el ADC se leen sensores (una LDR, un potenciómetro, un micrófono); con el DAC se sacan señales analógicas, como audio.

## El ADC

El LPC1768 tiene **un convertidor** de 12 bits por aproximaciones sucesivas y un **multiplexor de 8 entradas** (AD0.0–AD0.7) delante. Solo convierte un canal cada vez.

$$
V_{in} = \frac{RESULT}{2^{12}}\,(V_{REFP} - V_{REFN}) = RESULT\cdot\frac{3{,}3}{4096}
$$

Algunos pines: **AD0.0 en P0.23**, AD0.1 en P0.24, AD0.2 en P0.25, AD0.3 en P0.26 (compartido con la salida del DAC), AD0.4 en P1.30 y AD0.5 en P1.31.

**El reloj.** Sale del PCLK del ADC (PCLKSEL0, bits 25:24) dividido entre CLKDIV + 1, y **no puede pasar de 13 MHz**. Cada conversión tarda **65 ciclos**:

$$
F_{CLK\,ADC} = \frac{F_{PCLK}}{CLKDIV + 1} \le 13\ \text{MHz}
\qquad
t_{conv} = \frac{65}{F_{CLK\,ADC}}
$$

Con $F_{PCLK} = 25$ MHz, CLKDIV = 1 da 12,5 MHz y 5,2 µs por conversión (unas 190 000 por segundo). Cuanto más rápido el reloj, antes acaba.

**Disparar con un Match** es la forma limpia de muestrear a ritmo fijo: el Timer marca la frecuencia de muestreo y cada conversión empieza en el instante exacto, sin depender de la latencia de ninguna ISR.

Por eso AD0INTEN se escribe con **=** (y no con |=): así se pone el canal deseado y se borra ADGINTEN de paso.

```c
void adc_init(void) {
  LPC_SC->PCONP |= (1 << 12);                // alimentar el ADC (apagado tras el reset)
  LPC_PINCON->PINSEL1 |= (1 << 14);          // P0.23 = AD0.0
  LPC_PINCON->PINMODE1 |= (2 << 14);         // sin pull-up ni pull-down
  LPC_ADC->ADCR = (1 << 0)                   // canal 0
                | (1 << 8)                   // CLKDIV = 1: 12,5 MHz
                | (1 << 21);                 // PDN: encendido
  LPC_ADC->ADINTEN = (1 << 0);               // con =, para borrar ADGINTEN
  NVIC_EnableIRQ(ADC_IRQn);
}

void ADC_IRQHandler(void) {
  uint32_t r = LPC_ADC->ADGDR;               // leer borra DONE
  muestra = (r >> 4) & 0xFFF;
}
```

Para convertir: `LPC_ADC->ADCR |= (1 << 24);` (START = 001). Si la entrada no tiene pull-up ni pull-down, la resistencia interna no altera la tensión que se mide.

## El DAC

Un convertidor de **10 bits** con la salida **AOUT en P0.26** (función 10 de PINSEL1, bits 21:20). No necesita PCONP: basta con llevar el pin a su función.

$$
V_{out} = VALUE\cdot\frac{V_{REF}}{1024} = VALUE\cdot\frac{3{,}3}{1024}
$$

<Registro nombre="DACR" descripcion="valor y modo del DAC" campos={[
  { bits: '15:6', nombre: 'VALUE', que: 'El valor de 10 bits' },
  { bits: '16', nombre: 'BIAS', que: '0 = se estabiliza en 1 µs (hasta 1 MHz, 700 µA); 1 = 2,5 µs (hasta 400 kHz, 350 µA)' },
]} />

```c
LPC_PINCON->PINSEL1 |= (2 << 20);            // P0.26 = AOUT
LPC_DAC->DACR = (valor & 0x3FF) << 6;         // valor de 0 a 1023
```

**Generar una señal.** Se guarda un periodo en una tabla de N muestras y un Timer interrumpe a $f_s$; en cada interrupción se escribe la siguiente muestra en DACR. La frecuencia de salida es $f_{out} = f_s/N$. Lo mismo vale para reproducir audio grabado con el ADC: se muestrea y se reproduce a la misma $f_s$ (al menos 8 kHz para voz). Para no gastar CPU en cada muestra, se usa el **DMA**.

## Preguntas de examen

<details>
<summary>Un potenciómetro en AD0.0 debe leerse cada 10 ms sin tocar el ADC desde el programa principal. ¿Cómo lo montas?</summary>

Que el propio Timer dispare las conversiones. TIMER0 con MR1 = 5 ms·F_tick − 1, reset en MR1 y EMC1 = 11 (conmutar): MAT0.1 sube cada 10 ms. En AD0CR, START = 100 (MAT0.1) y EDGE = 0 (subida). `AD0INTEN = (1 << 0)` y en la ISR del ADC se guarda `(ADGDR >> 4) & 0xFFF`. El conmutar es lo que crea el flanco: por eso el Match va a la mitad del periodo de muestreo. *(Respuesta redactada a partir de los apuntes y del UM10360.)*

</details>
