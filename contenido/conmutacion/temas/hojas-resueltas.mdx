## Cómo de fiables son los resultados

> **Ninguna de estas soluciones es la del profesor**, salvo el ejercicio 3 de Red3. No hay solución publicada de las demás hojas. Cada resultado se ha calculado con código (Erlang B por recursión) y contrastado de forma independiente entre varios modelos y fuentes externas, y con los apuntes manuscritos de un compañero en el Múltiplex. En cada página marco la **confianza** de cada apartado:
>
> - **Alta:** coinciden todas las resoluciones y la norma.
> - **Media:** depende de una lectura del enunciado, con una alternativa razonable.
> - **Baja:** el enunciado es inconsistente; doy las lecturas posibles.
>
> Si consigues la solución de clase, contrástala y dime las diferencias para corregir la web.

## Constantes que se usan en todo

| Dato | Valor | De dónde sale |
| --- | --- | --- |
| Multitrama de 26 tramas | 120 ms | Cx_Multiplex, duración de las tramas |
| Trama | 120/26 = 4,615 ms | idem |
| Ráfaga (una ranura) | 4,615/8 = 0,577 ms | idem |
| Multitrama de 51 tramas | 51 · 4,615 = 235,38 ms | idem |
| Ráfaga normal | 148 bits + 8,25 de guarda = 156,25 tiempos de bit; 114 bits de datos | Cx_Multiplex, ráfaga normal |
| Ráfaga de acceso | 8 + 41 + 36 + 3 + 68,25 = 156,25 bits | Cx_Multiplex, ráfaga de acceso |
| Tasa de la portadora | 156,25 / 0,577 ms = 270,83 kbit/s en 200 kHz | idem |
| Bloque CCCH | 4 ráfagas | Cx_Multiplex, combinaciones IV y V |
| Comb. IV | 9 bloques CCCH (36 ráfagas) y 51 ranuras RACH por MF51 | idem |
| Comb. V | 3 bloques CCCH (12 ráfagas), 27 ranuras RACH y 4 SDCCH por MF51 | idem |
| Perfil de tráfico bajo | 1 frecuencia: 1 comb. V + 7 comb. I o II → 4 SDCCH y 7 TCH/F (o 14 TCH/H) | Cx_Multiplex, asignaciones típicas |
| Perfil de tráfico medio | 4 frecuencias: 1 comb. IV + 2 comb. VII + 29 comb. I o II → 16 SDCCH y 29 TCH/F (o 58 TCH/H) | idem |
| Abis | 15 canales de 64 kbit/s por E1 × 4 llamadas = 60 circuitos por E1 | Red2 ejercicio 2 y Red3 (en Red2 ejercicio 1 se extrapola) |
| Estrategia típica | RACH → AGCH → SDCCH (fase inicial) → FACCH/TCH (resto) | Cx_Red_Conexiones |

**Erlang B:** B(0) = 1 y B(n) = A · B(n−1) / (n + A · B(n−1)). Para «máximo de usuarios» se busca el A que da el bloqueo límite y se divide por el tráfico de un usuario.
